## 仍缺少的来源内容

- **45 场**在源站共用了其他比赛的详情链接，无法凭链接确认本场地图与选手数据。这些比赛只保留各自的索引赛果，不借用链接所指另一场的记录。
- **2 场**详情页返回 404：OWTV ID 12、14；索引赛果保留。
- **22 场**在源站已标结束，但至少一方比分缺失，且没有胜者字段。保留未知，不补成 0、不猜胜负。
- **32 场**尚无比赛日期，数据库保留，日期赛程列表不参与排序。
- Eis、Hanbin 的当前头像地址返回不可用内容；已有可用本地头像保留，缺少时使用占位图。

## 程序校验

- SQLite 完整性检查通过。
- 选手记录、地图、参赛队关联检查通过，没有孤立记录或归属到其他比赛的地图。
- 1,276 场有日期比赛经过加载、同步、重复同步回放，没有丢失、重复 ID 或队伍/比分错配。
- 相同大小的新快照也会更新；用户自行新增的比赛和较新详情保留。
- 解析器先拼接网页传输片段，再读取地图与选手记录，避免只保存到最后一张地图。

采集脚本：`tools/collect_owtv_database.py`。数据库检查：`python tools/audit_owtv_database.py`。赛程合并回放：`node tests/audit_match_merge.mjs`。
